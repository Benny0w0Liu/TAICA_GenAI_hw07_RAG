# 世界射箭總會射箭裝備｜RAG 練習資料集

整理日期：2026-11-01

資料集包含 15 份 UTF-8 繁體中文 TXT 教學摘要（每個指定類別 3 份）、`sources.csv` 來源清單及 `問題集.csv` 檢索測試問題。每類的三份文件分別聚焦概覽、器材或分級，以及技術或競賽等不同子題；資料依據各文件標示的世界射箭總會公開網頁整理，不是網站全文或官方規則的替代品。

## 建議使用方式

1. 將各 TXT 視為獨立文件，按段落或固定 token 數切塊。
2. 建立 embeddings 並檢索 top-k，要求模型根據檢索到的內容回答並附上來源。
3. 使用 `問題集.csv` 測試各主題檢索及「文件未提供答案」時是否能避免臆測。
4. 裝備規定及運動分級可能修訂；實際參賽應核對世界射箭總會最新規則及分類規定。

本資料集以短篇改寫摘要供教學與檢索練習使用，不提供完整器材規則、個人醫療或分級判定。若需重製或散布來源網頁全文、圖片，請先確認網站的權利與授權條款。
